# sait-koleg — новий сайт КПІК

Оновлений адаптивний сайт Кам'янець-Подільського фахового коледжу індустрії, бізнесу та інформаційних технологій (редизайн [kpik.org.ua](https://kpik.org.ua/)).

Статичний сайт на HTML, CSS і JavaScript без збірки та залежностей. Його можна відкрити будь-яким браузером або розмістити на будь-якому хостингу, зокрема на GitHub Pages.

## Сторінки

| Файл | Розділ |
| --- | --- |
| `index.html` | Головна: банер, швидкі посилання, відділення, переваги, новини, контакти |
| `about.html` | Про коледж: загальна інформація, історія, адміністрація, матеріальна база, фотогалерея, міжнародна співпраця |
| `specialties.html` | Спеціальності з фільтром за відділенням |
| `admission.html` | Вступ 2026: правила прийому, програми, етапи, документи, приймальна комісія, FAQ |
| `students.html` | Студенту: розклад, дистанційне навчання, бібліотека, гуртожиток, психологічна служба, безпека |
| `news.html` | Новини |
| `contacts.html` | Контакти, карта, форма зворотного зв'язку |
| `transparency.html` | Публічна інформація (ст. 30 Закону «Про освіту») |
| `404.html` | Сторінка «не знайдено» |

## Що всередині

- **Адаптивність (mobile-first):** від 320 px до широких моніторів; на телефоні є бокове меню з підменю-акордеонами, таблиці перебудовуються в картки, зміст сторінки показується горизонтальними «чипами».
- **Доступність:** посилання «Перейти до основного вмісту», керування з клавіатури (Esc, Tab), `aria`-атрибути, режим «Людям з порушенням зору» (більший шрифт і контраст, зберігається в браузері), повага до `prefers-reduced-motion`.
- **SEO:** мета-описи, Open Graph, мікророзмітка `CollegeOrUniversity` на головній.

## Структура

```
assets/css/style.css   — усі стилі (кольори та розміри — змінні в :root)
assets/js/main.js      — меню, фільтр спеціальностей, галерея, форма, анімації
assets/img/logo.svg    — тимчасовий логотип-монограма
```

## Запуск локально

```bash
python3 -m http.server 8000
# відкрийте http://localhost:8000
```

## Що потрібно доповнити перед публікацією

- **Фото.** Зараз використано вільні фото з [Unsplash](https://unsplash.com/license), які завантажуються з CDN Unsplash. Замініть їх на фото коледжу: покладіть файли в `assets/img/photos/` і змініть `src` у тегах `<img>` (якщо фото не завантажиться, замість нього показується фірмовий градієнт).
- **Логотип.** Замініть `assets/img/logo.svg` на офіційний.
- **Новини.** Новини в `index.html` і `news.html` демонстраційні. Замініть їх на актуальні матеріали.
- **Документи.** Посилання з `href="#"` (правила прийому, розклад, публічна інформація) треба вказати на реальні PDF-файли.
- **Перевірка даних.** Перевірте з адміністрацією контакти, перелік спеціальностей та освітніх програм.
